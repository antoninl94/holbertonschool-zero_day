# Holberton School - Zero Day

This repository is part of the **Holberton School** curriculum and is focused on the introductory phase of the program. It covers basic system setup and essential tools for the learning journey ahead, as well as a brief introduction to the Linux command line.

## Table of Contents

- [Overview](#overview)
- [Tasks](#tasks)
- [Technologies Used](#technologies-used)
- [Installation](#installation)

## Overview

The **Zero Day** project is a foundational learning experience. It is intended to provide an introduction to essential tools and practices, including:

- Setting up a development environment.
- Using Git for version control.
- Learning basic Linux commands and navigation.
- Understanding the basic structure of a repository.
- Setting up basic configurations for future projects.

## Tasks

This directory contains various tasks and exercises related to setting up the development environment and getting familiar with version control and basic Linux operations:

- **[0-hello_world](./0-hello_world)**: Creating a "Hello, World!" script to verify your environment is set up correctly.
- **[1-setup](./1-setup)**: Installing necessary tools such as Git, GCC, and editors like Vim or Nano.
- **[2-using_git](./2-using_git)**: Introduction to Git for version control, including basic commands like `git init`, `git add`, `git commit`, and `git push`.
- **[3-basic_shell_commands](./3-basic_shell_commands)**: Basic Linux shell commands for navigation and file manipulation (e.g., `cd`, `ls`, `cp`, `mv`).
- **[4-text_editor](./4-text_editor)**: Using a text editor like Nano or Vim to create and edit files.
- **[5-first_commit](./5-first_commit)**: Making the first commit using Git to track the changes in your project.
  
Each task is designed to provide you with hands-on practice and is accompanied by explanations and code samples.

## Technologies Used

- **Git**: Version control system to manage code changes and collaboration.
- **Linux/Unix**: Operating system used to execute the majority of the tasks and exercises.
- **Bash**: Shell script for automating tasks.
- **Vim/Nano**: Text editors used to edit files within the terminal.
- **Makefile**: For automating common tasks like compiling code and running tests.
